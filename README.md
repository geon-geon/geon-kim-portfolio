# 김건 / Geon Kim — Portfolio

금융 AI · 디지털 서비스 기획 지원을 위한 한국어 정적 포트폴리오입니다.

## 실행

`index.html`을 브라우저로 열거나 이 폴더에서 `python -m http.server 4173`을 실행합니다. 별도 빌드·패키지 설치·API 키가 필요하지 않습니다.

## GitHub Pages

이 폴더의 내용을 저장소 루트에 올린 후 **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**를 선택합니다. `.nojekyll`을 함께 보존하세요. 상대경로를 사용하므로 프로젝트 Pages의 하위 경로에서도 작동합니다.

[GitHub 공식 배포 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 파일

- `index.html`: 공개 본문, SEO 메타데이터, 섹션 앵커.
- `styles.css`: 반응형·인쇄 스타일, 키보드 포커스와 모션 감소 지원.
- `script.js`: 현재 섹션 표시. JavaScript 없이도 본문·링크 사용 가능.
- `assets/*.webp`: 제공된 연구 그림 4종과 실제 프로젝트 화면 1종.
- `.nojekyll`: 정적 파일을 그대로 배포.

## 출처·이미지

연구 및 경력 내용은 사용자가 제공한 Master CV와 전공소개서에 근거합니다. 원본 PDF와 개인 연락처는 포함하지 않습니다.

- `eeg-topography.webp`: 전공소개서 p.4의 저·고베타 두피 지도. Gamma 설명은 본문 결과이며 그림의 표시 대역과 구분합니다.
- `research-pipeline.webp`: 전공소개서 p.3의 원본 분석 파이프라인.
- `eye-tracking.webp`: 전공소개서 p.5의 초기·후기 처리 그래프.
- `laboratory.webp`: 전공소개서 p.7의 설비 도면 중 실험실 구조 부분. 도면 우측 표제·관리 영역 제외.
- `attention-compass.webp`: Attention Compass `research-v034/screenshots/03-terrain-final.png`에서 잘라낸 가상 사용자 예시 화면. 기사 제목은 [SBHNews / 센서스튜디오](https://www.sbhnews.com/data-use), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Attention Compass가 분석·임베딩을 추가했으며 이 사이트에서는 화면 주변 영역을 잘라 WebP로 변환했습니다.

원본 그림의 수치·색상을 다시 그리거나 변경하지 않았습니다. 별도 명시가 없는 이미지의 재사용 권리를 포괄적으로 부여하지 않습니다.

## 공개 범위

이 사이트는 연구·제품 사례를 설명하는 포트폴리오입니다. Attention Compass 실행 서버, 캐시, 실제 사용자 정보, 모델 가중치, 뉴스 원자료 전체를 포함하지 않습니다. 공개 이메일을 추가할 경우 본인의 공개 의사를 확인한 주소만 사용하세요.
